C. Hybrid

Workers remain visible, but a small target status strip is always present below them.

My recommendation: C

  • Worker state is the most useful live debugging signal, especially with hashing/copying/verifying phases.
  • Target progress matters because the app copies to multiple destinations and users want confidence each target is advancing.
  • The target strip gives that confidence without stealing too much filename space.

Tradeoff

  • It consumes one or two extra rows, so narrow terminals need a fallback that hides the target strip first.
