C. No File Preview

Summary stays focused on correctness and totals. File browsing is omitted from terminal output.

My recommendation: A

  • Aggregates tell you what happened without turning the summary into a long scrollback dump.
  • A capped preview is still useful for sanity-checking filenames and layout output.
  • It preserves the correctness-first shape: target results, failures, then breakdown/preview.

Tradeoff

  • The terminal will not show every copied file unless a future verbose/report option is added.
